# SiteForge Studio – Design Engineering & Digital Platform

A high-performance, multi-page digital flagship and website platform engineered with React 19, TypeScript, Tailwind CSS v4, and Vite.

---

## 🚀 Features

- **Multi-Page Architecture**: 6 dedicated responsive pages:
  - **Overview (`/home`)**: High-impact editorial hero, full-width quantitative proof strip, featured disciplines preview, marquee project spotlight, and leadership endorsements.
  - **Services & Disciplines (`/services`)**: In-depth breakdown of 5 core engineering practices, 4-stage sprint methodology, and interactive production stack filter matrix.
  - **Case Studies & Production Work (`/work`)**: Filterable project gallery (`Fintech`, `Hardware`, `Developer SaaS`, `Luxury Brand`) with verified business metrics and deep architectural inspection modal.
  - **About Studio & Leadership (`/about`)**: Studio manifesto, London & Zurich operating hubs, the 4 Studio Invariants, and leadership portraits for **David Wrekman**, **Atash Mitchun**, and **Hazzin Brian**.
  - **Scope Estimator & Pricing (`/pricing`)**: Real-time project cost calculator, transparent sprint tiers comparison table, and 100% Core Web Vitals warranty.
  - **Project Initiation Brief (`/contact`)**: Multi-step scoping inquiry form supporting preloaded parameters, direct communication channels, and the 24-Hour Discovery Process timeline.
- **Command Palette (`Cmd+K` / `Ctrl+K`)**: Keyboard-first search modal for instant navigation across all pages, themes, templates, responsive viewport simulators, and settings.
- **Studio Customizer & Live SEO Editor**:
  - Live meta title and description editors with character counters and length guidance.
  - Interactive Google SERP preview card updating in real time.
  - Dynamic browser document title and meta tag synchronization.
  - 5 curated color palettes (Obsidian, Light, Cobalt, Luxury Stone, Emerald Forest).
  - 4 industry presets (Agency Studio, Developer SaaS, Industrial Hardware, Strategic Advisory).
  - Responsive viewport simulator (Desktop 1440px, Tablet 768px, Mobile 390px).
- **Vite Asset Bundler**: Production-grade image pipeline with zero broken images in production builds.

## 💻 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/<your-username>/<your-repo-name>.git
   cd <your-repo-name>
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Production Build**:
   ```bash
   npm run build
   npm run preview
   ```

## 📦 Pushing to GitHub

To link this codebase to a new repository on GitHub:

1. **Create an empty repository** on [GitHub](https://github.com/new) (do not initialize with README or license).
2. **Run the following commands in your terminal**:
   ```bash
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git branch -M main
   git push -u origin main
   ```
